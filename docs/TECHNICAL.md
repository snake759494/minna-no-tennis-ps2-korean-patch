# 기술 설명

## 디스크 구성
- 실행파일 `SCPS_151.13` 안에 디스크 파일의 LBA 표(32바이트 엔트리: 이름, 시작 LBA, 끝 LBA, 섹터 수)가 있습니다. 파일을 옮기거나 키우면 이 표도 고쳐야 합니다. `build.py`가 원래 LBA로 엔트리를 찾아 새 위치로 바꿉니다. 실행파일이 바뀌므로 PCSX2 CRC도 `A35F68F7`에서 `A35F2139`로 바뀝니다.
- 원래 자리에 들어가지 않는 파일은 ISO 끝에 붙이고 디렉터리 레코드와 볼륨 크기를 갱신합니다(`isopatch.py`).

## XB 아카이브
- 헤더 `xe`, 버전 0x100, 파일 수, 파일마다 (출력 크기, 방식<<28 | 오프셋/4), 이어서 이름표 블록.
- 방식 0 = 허프만 후 LZ, 1 = 허프만, 2 = LZ, 3 = 무압축. 블록은 (원래 크기, 압축 크기) 다음 데이터입니다.
- LZ 토큰: 하위 2비트 00 = 리터럴 1~64바이트, x1 = 2바이트 매치(길이 3~10, 거리 ≤4095), 10 = 3바이트 매치(길이 3~1026).
- 다시 묶을 때는 바뀐 파일만 자체 LZ 인코더로 압축하고, 나머지는 원본 블록을 그대로 복사합니다(`xb.py`).

## 게임 글꼴
- `data/common/gffont16.bin`: 22×22 4bpp 글리프, 바이트 RLE. 글리프 번호는 JIS 선형 번호 − 2입니다.
- 한자 영역(亜부터)에 KS X 1001 한글 2,350자를 그려 넣었습니다. 게임은 Shift-JIS 2바이트 코드를 그대로 그리므로, 한글 k번째 글자는 JIS 선형 1410+k에 해당하는 SJIS 코드로 적습니다(`kfont.py encode`).
- 값 1~4는 바깥쪽으로 옅어지는 외곽선, 5~15는 본체 농도입니다. 원본처럼 테두리가 있는 둥근 글자가 되도록 나눔스퀘어 네오 ExtraBold 18.5px을 4배 슈퍼샘플링해 그렸습니다.

## 문자열
- 설명 띠·확인창·메모리 카드 메시지 등은 `ZZBIN/MENU.BIN`에 있습니다. 문자열 칸은 다음 0이 아닌 바이트 앞까지이며, 그 안에서 제자리 교체합니다(`menubin.py`). 칸을 넘는 번역은 빌드 때 경고합니다.
- 실행파일 안 플레이 스타일 이름(オール/ネット/ベース/ビッグ)은 번역하면 코트를 바꾼 뒤 COM이 서브하지 않는 문제가 생겨 원문으로 남겼습니다(`ELF_STR` 환경 변수로만 켜짐).

## 그림 글자
- 메뉴·HUD·로딩 팁 등은 TIM2(4/8bpp CLUT, CSM1 스위즐, 알파 0x80=불투명)입니다(`tim2.py`).
- `imgtext.py`가 상자마다 원본 글자의 본체색·외곽선색을 행 단위로 샘플링하고, 원본 글자를 지운 뒤(투명·주변색·행 복사·인페인트 등) 한국어를 그려 원 팔레트의 가장 가까운 색으로 되돌립니다.
- 원본 글자가 차지하던 가로 범위를 재서, 한국어가 그 밖으로 나가면 옮기거나 가로로 줄입니다(`_fit`). 앞부분이 잘리지 않도록 정렬 기준으로 자릅니다.
- 메인 메뉴의 3D 간판은 MTL/MTI 텍스처(`mti.py`, `translation/sign3d.py`), 타이틀 로고 자막·게임오버 말풍선은 8bpp BMP(`translation/bmps.py`)입니다.

## 16:9 와이드 패치
- PCSX2 패치 DB의 원본판 패치와 같은 코드입니다. 0x139120의 FOV 저장 명령을 0x1C090C의 빈 공간으로 점프시켜 가로 시야에 0.75를 곱하고, 0x137984에서 2D 좌표 기준 폭(640→856)을 바꿔 HUD 비율을 보정합니다.
- 한글패치는 이 주소들을 건드리지 않습니다(원본판과 한글판의 해당 워드가 같은 것을 확인했습니다). 따라서 CRC만 바꿔 그대로 씁니다.
