# 모두의 테니스 PS2 한글패치

PS2 일본판 **모두의 테니스(みんなのテニス, SCPS-15113)**용 비공식 한국어 패치입니다. **설명 띠·메뉴·확인창·메모리 카드 메시지** 등 게임 문자열과, **메뉴 제목·버튼·캐릭터 선택·경기 HUD·결과·스테이터스·트레이닝·챌린지 모드·로딩 팁·튜토리얼·메인 메뉴 3D 간판·타이틀 로고 자막** 등 그림 글자를 한국어로 바꿨습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.2 (2026-11-21)**입니다.

[패치 다운로드](https://github.com/snake759494/minna-no-tennis-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 한글패치 **Minna_no_Tennis_PS2_KO_v1.4.xdelta**와 와이드 패치 **SCPS-15113_A35F2139.pnach**입니다. 저장소에는 제작 소스와 한국어 번역만 공개합니다. 원본·완성 디스크 이미지, 추출한 게임 파일, 일본어 원문, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

『모두의 테니스』는 Sony Computer Entertainment가 2006년에 낸 PS2용 테니스 게임입니다(개발 Clap Hanz). 『모두의 골프』 제작진이 만든 작품으로, 간단한 버튼 조작과 타이밍으로 누구나 테니스를 즐길 수 있습니다. 챌린지 모드에서 랭크를 올리며 캐릭터·코스튬·심판·코트를 모읍니다.

이 패치는 **PS2 일본판 SCPS-15113(Japan, Asia)의 DVD ISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Minna no Tennis (Japan, Asia).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Minna_no_Tennis_PS2_KO_v1.4.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Minna no Tennis (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Minna no Tennis (Japan, Asia).iso' '.\Minna_no_Tennis_PS2_KO_v1.4.xdelta' '.\Minna no Tennis (Korean).iso'
```

원본판 세이브 스테이트는 쓰지 마세요. 메모리 카드 세이브는 원본판과 호환됩니다.

## 16:9 와이드 패치 사용법 (PCSX2 2.x)

게임 옵션에는 화면비 설정이 없습니다. `SCPS-15113_A35F2139.pnach`는 **한글패치를 적용한 ISO 전용**입니다. 한글패치가 실행파일(ELF)의 파일 위치 표를 고쳐 게임 CRC가 `A35F68F7`에서 `A35F2139`로 바뀌므로, PCSX2에 내장된 원본판 와이드 패치는 자동으로 적용되지 않습니다. 이 파일은 그 내장 패치(ElHecht 제작, NTSC-J 이식 Arapapa)를 한글판 CRC에 맞춰 옮긴 것입니다. 패치가 고치는 코드(0x139120, 0x137984)는 한글패치가 건드리지 않습니다.

1. PCSX2에서 한글판 ISO를 한 번 부팅하고 종료합니다. 로그(도구 > 로그 창 보기)나 게임 목록 속성에서 CRC가 `A35F2139`인지 확인합니다.
2. `SCPS-15113_A35F2139.pnach`를 PCSX2 `patches` 폴더에 복사합니다. 파일 이름을 바꾸지 마세요.
   - 설치판 기본 위치: `문서\PCSX2\patches`
   - 포터블판: PCSX2 폴더 안의 `patches`
   - 정확한 위치는 설정 > 폴더에서 "패치" 항목으로 확인할 수 있습니다.
3. 게임 목록에서 이 게임을 우클릭하고 **속성 > 패치**를 엽니다. **Widescreen 16:9**에 체크합니다.
4. 같은 속성 창의 **그래픽 > 화면**에서 **화면비(Aspect Ratio)**를 **와이드스크린 (16:9)**으로 바꿉니다. pnach의 `gsaspectratio=16:9` 줄 때문에 패치를 켜면 화면비가 자동으로 바뀌기도 합니다.
5. 게임을 시작하면 화면 위에 "1개의 게임 패치가 활성화되었습니다"가 뜹니다. 경기 화면의 3D 시야가 좌우로 넓어지고 HUD가 16:9 비율에 맞게 보정됩니다.

주의
- 원본 일본판 ISO에는 이 파일이 필요 없습니다. PCSX2 내장 와이드 패치를 그대로 켜면 됩니다.
- 경기 화면만 보정됩니다. 타이틀·메인 메뉴·캐릭터 선택·옵션 같은 2D 메뉴 화면은 가로로 늘어나 보입니다.
- 패치가 목록에 없으면 파일 이름의 CRC(`A35F2139`)와 실제 게임 CRC가 같은지, `patches` 폴더 위치가 맞는지 확인하세요.
- 와이드 패치를 끄려면 속성 > 패치에서 체크를 풀고 화면비를 4:3으로 되돌립니다.

## 한글화 범위

- 게임 문자열 약 490개(MENU.BIN): 화면 아래 설명 띠(모드·캐릭터·코트 설명), 확인창, 메모리 카드·세이브 메시지, 옵션 설명 등
- 게임 글꼴: 한글 2,350자(KS X 1001 전체)
- 그림 글자 195장(글자 상자 1,000여 곳): 메인 메뉴·화면 제목, 캐릭터 선택·파라미터, 최종 확인, 경기 HUD(세트·게임·등급), 시합 시작·게임 세트·브레이크 등 알림, 스코어 보드·스테이터스, 트레이닝 모드 메뉴·설명·결과, 챌린지 모드 랭크·상대 정보·획득 아이템, 로딩 팁, 튜토리얼, 상품 획득 화면, 키 설정
- 메인 메뉴 3D 간판, 타이틀 로고·로딩 화면 로고 아래 한글 자막("모두의 테니스"), 게임오버 말풍선
- 글꼴: 나눔스퀘어 네오(원본 둥근 고딕체와 비슷한 글꼴), 아주 작은 글자에 갈무리, 3D 간판 일부에 서울한강체
- 원문 유지: 로고, 저작권 표기, 영문 UI 글자(Now Loading 등), 이름 입력판의 가나 문자(입력용), 기본 데이터 이름 "みんテニ", 플레이 스타일 이름 4종(아래 참고)

## 알려진 한계

- 실행파일 안의 플레이 스타일 이름(オール/ネット/ベース/ビッグ)은 번역하면 코트 변경 뒤 COM이 서브하지 않는 문제가 생겨 원문으로 남겼습니다.
- 와이드 패치는 경기 화면만 보정하며, 2D 메뉴 화면은 가로로 늘어납니다.
- PCSX2에서 타이틀, 메인 메뉴, 옵션, 캐릭터 선택, 최종 확인, 로딩, 경기 HUD·알림, 스코어 보드·스테이터스, 트레이닝 모드(서브·발리), 챌린지 모드(비기너 랭크 시합)를 확인했습니다. 챌린지 상위 랭크와 승리 후 랭크업·아이템 획득 연출, 실기에서의 동작은 확인하지 못했습니다. 문제가 있으면 이슈로 알려 주세요.
